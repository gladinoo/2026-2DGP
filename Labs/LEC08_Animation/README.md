## 🔍 핵심 구현 세부사항

### 1. 화면 중앙 렌더링 & 50% 이상 확대 (기본 1, 2)
- 캔버스 크기: `800 x 600`
- 렌더링 중심 좌표: `(CENTER_X, CENTER_Y) = (400, 300)`
- 확대 비율: `SCALE = 8.5` (소닉 원본 높이 약 40px -> 확대 후 약 340px, 화면 높이 600px의 **56.7%** 차지)

### 2. 한 동작 5회 반복 및 1초 정지 (과제 세부 요건)
- `play_action(action_frames, repeat_count=5, frame_delay=0.1)`:
  - 지정된 동작 프레임들을 5회 반복 루프로 재생
  - 5회 완료 후 `delay(1.0)` 호출로 동작 전환 시 정확히 1초간 정지

### 3. 복잡한 스프라이트 시트 처리 (보너스 1: +2점)
- 프레임마다 너비와 높이가 다른 가변 크기 바운딩 박스를 튜플 형태로 관리:
  ```python
  IDLE_FRAMES = ((1, 447, 29, 39), (31, 447, 26, 38), ...)
  WALK_FRAMES = ((8, 408, 26, 37), (37, 408, 27, 37), ...)
  ```

### 4. 동작별 상이한 프레임 수 (보너스 2: +2점)
- **IDLE (대기 / 발 구르기)**: 5개 프레임
- **WALK (걷기)**: 12개 프레임
- **RUN (달리기)**: 4개 프레임
- **ROLL (스핀 / 구르기)**: 8개 프레임
